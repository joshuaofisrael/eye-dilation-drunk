# Eye Dilation Drunk — native iOS (legacy)

Original SwiftUI + AVFoundation + Vision implementation.

Prefer the **Expo Go** app at the repository root for day-to-day use.

## Open in Xcode

1. Open `EyeDilationDrunk.xcodeproj` on a Mac with Xcode 15+.
2. Select your Team under Signing & Capabilities.
3. Run on a **physical iPhone** (torch required).

Bundle ID: `com.joshuaisrael.EyeDilationDrunk`
